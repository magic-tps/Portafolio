# Portafolio

Portafolio web de Tomas Alonso Pastor Salazar, desarrollado con Next.js,
React, TypeScript y Tailwind CSS.

## Contenido

- Perfil profesional enfocado en inteligencia artificial, vision computacional,
  OCR, analisis de datos y desarrollo web.
- Seccion de experiencia academica y laboral.
- Proyectos con demos y repositorios.
- Stack tecnico, certificaciones, educacion y contacto.
- Descarga directa del CV actualizado.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Desarrollo local

```bash
npm run dev
```

Luego abre:

```text
http://localhost:3000
```
